AeroRota プライバシーポリシー

最終更新日: 2026年9月19日

本ポリシーは、iOSアプリ「AeroRota」(以下「本アプリ」)における利用者情報の取り扱いについて説明するものです。 本アプリは個人開発者により開発・提供されています。

1. 収集する情報

本アプリは、勤務予定などの入力データを端末内のローカルストレージ(SwiftData)にのみ保存します。 これらのデータが開発者のサーバーに送信されることはなく、開発者がユーザーのデータを収集・閲覧することもありません。

本アプリは、広告SDK・アクセス解析SDK・クラッシュレポートSDKなど、第三者にデータを送信するトラッキング機能を一切含んでいません。

2. Googleカレンダー連携について

本アプリには、作成した勤務予定をユーザー自身のGoogleカレンダーにエクスポート(登録・削除)する任意機能があります。 この機能を利用する場合、Googleが提供する認証(Google Sign-In)を通じてユーザーの同意を得たうえで、以下のスコープのみを使用します。

  • https://www.googleapis.com/auth/calendar.events(カレンダーの予定の閲覧・作成・削除)

この連携により送信されるデータは、ユーザーの端末からGoogleのサーバーへ直接送信されるものであり、開発者のサーバーを経由することはありません。 また、この機能はユーザーが明示的に操作した場合(エクスポート・削除操作)にのみ実行されます。

AeroRotaによるGoogleユーザーデータの使用および他アプリへの転送は、 限定的な使用に関する要件を含む Google API サービス ユーザーデータ ポリシー を遵守します。

3. 第三者への提供

本アプリは、上記のGoogleカレンダー連携(ユーザー自身のGoogleアカウントへの連携)を除き、ユーザーのデータを第三者に提供・販売することはありません。

4. データの削除

本アプリ内のデータは、アプリ内の削除操作、またはアプリのアンインストールによって端末から削除されます。 Googleカレンダーに登録された予定は、本アプリの削除機能、またはGoogleカレンダー側の操作で削除できます。 Googleアカウントとの連携の解除は、 Googleアカウントの管理画面 からいつでも行えます。

5. 子どものプライバシー

本アプリは航空管制官の勤務予定管理を目的としており、13歳未満の子どもを対象としていません。

6. 本ポリシーの変更

本ポリシーの内容は、必要に応じて変更される場合があります。変更後の内容は本ページに掲載された時点で効力を持ちます。

Privacy Policy (English)

Last updated: September 19, 2026

This Privacy Policy explains how the iOS app "AeroRota" (the "App") handles user information. The App is developed and provided by an individual developer.

1. Information We Collect

The App stores all user-entered data (such as work schedules) locally on the device using SwiftData. No data is transmitted to, or collected by, any server operated by the developer.

The App does not include any advertising SDK, analytics SDK, or crash-reporting SDK that transmits data to third parties.

2. Google Calendar Integration

The App includes an optional feature to export work schedules to the user's own Google Calendar (create and delete events). This feature uses Google Sign-In with the following OAuth scope only, after obtaining the user's consent:

  • https://www.googleapis.com/auth/calendar.events (view, create, and delete calendar events)

Data sent through this feature travels directly from the user's device to Google's servers and never passes through any server operated by the developer. This feature is only triggered by an explicit user action (export or delete).

AeroRota's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

3. Third-Party Sharing

Other than the Google Calendar integration described above (which connects to the user's own Google account), the App does not share or sell user data to any third party.

4. Data Deletion

Data stored in the App can be deleted via in-app deletion features or by uninstalling the App. Events created in Google Calendar can be removed via the App's delete feature or directly in Google Calendar. Users can revoke the App's access to their Google account at any time via Google Account permissions.

5. Children's Privacy

The App is intended for scheduling by air traffic controllers and is not directed at children under 13.

This Policy may be updated from time to time. Changes take effect once posted on this page.
