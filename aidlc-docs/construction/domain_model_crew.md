# Crew（クルー） - Entity

## 概要
勤務サイクルの基準となるグループ。

## 関連ストーリー
US-1.1〜US-1.5

---

## 属性

| 属性名 | 型 | 説明 |
|-------|-----|------|
| id | ID | 一意識別子 |
| name | String | クルー名 |
| cycleStartDate | Date | サイクル開始日（42日サイクルの起算日） |

---

## 振る舞い

※ Entityは属性のみを持つデータ構造として実装。
※ create, update, delete 操作は CrewRepository の責務として実装する。

---

## 関連

| 関連先 | 多重度 | 説明 |
|-------|-------|------|
| Cell | 1 : 0..7 | 1つのクルーは最大7つのセルを持つ |
