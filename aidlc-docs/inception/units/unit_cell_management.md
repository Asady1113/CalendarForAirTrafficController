# セル管理ユニット

## 概要
クルーに紐づく「セル」とそのサイクル構成を管理する機能群

## スコープ
セルのCRUD操作、サイクル構成（7ラウンドの順序・種別）の設定、セル選択によるカレンダー画面への遷移

---

## ユーザーストーリー

### US-2.1: セル一覧の表示
**タイトル**: セル一覧を表示する

As a 航空管制官,
I want 選択中のクルーに紐づく全てのセルを一覧で確認したい,
So that 自分が所属するセルを選択できる.

**受け入れ基準**:
- [ ] 選択中のクルーに紐づく全セルが一覧表示される
- [ ] 各セルのセル名が表示される
- [ ] セルが未登録の場合、空の状態が適切に表示される
- [ ] 現在選択中のクルー名が画面上部に表示される

---

### US-2.2: セルの新規作成（サイクル構成含む）
**タイトル**: 新しいセルをサイクル構成と共に登録する

As a 航空管制官,
I want 新しいセルをサイクル構成と一緒に登録したい,
So that 自分のセルと勤務パターンを一度に設定できる.

**受け入れ基準**:
- [ ] セル名を入力できる
- [ ] 7つのラウンドの種別（夜勤あり／夜勤なし／夜勤なし・B4あり）を選択できる
- [ ] 登録ボタンを押すとセルとサイクル構成が保存される
- [ ] 登録後、セル一覧に新しいセルが表示される
- [ ] セルは現在選択中のクルーに紐づけられる

---

### US-2.3: セルの編集
**タイトル**: 既存のセル情報を編集する

As a 航空管制官,
I want 既存セルのセル名とサイクル構成を編集したい,
So that セル情報や勤務パターンの変更に対応できる.

**受け入れ基準**:
- [ ] 編集したいセルを選択できる
- [ ] セル名を変更できる
- [ ] 各ラウンドの種別（夜勤あり／夜勤なし／夜勤なし・B4あり）を変更できる
- [ ] 保存ボタンを押すと変更が保存される

---

### US-2.4: セルの削除
**タイトル**: 不要なセルを削除する

As a 航空管制官,
I want 不要になったセルを削除したい,
So that セル一覧を整理できる.

**受け入れ基準**:
- [ ] 削除したいセルを選択できる
- [ ] 削除前に確認ダイアログが表示される
- [ ] 削除を確定するとセルが削除される

---

### US-2.5: セルの選択（カレンダー画面への遷移）
**タイトル**: セルを選択してカレンダー画面へ進む

As a 航空管制官,
I want セルを選択してカレンダー画面へ進みたい,
So that そのセルの勤務予定を確認できる.

**受け入れ基準**:
- [ ] セル一覧から特定のセルを選択できる
- [ ] 選択後、カレンダー画面へ遷移する
- [ ] カレンダー画面では選択したセルの勤務予定が表示される

---

### US-2.6: クルー管理画面への戻り
**タイトル**: クルー管理画面へ戻る

As a 航空管制官,
I want セル管理画面からクルー管理画面へ戻りたい,
So that 別のクルーを選択できる.

**受け入れ基準**:
- [ ] 戻るボタンまたはナビゲーションが表示される
- [ ] 操作するとクルー管理画面へ遷移する
