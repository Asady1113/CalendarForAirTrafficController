# 勤務予定表示ユニット

## 概要
計算された勤務予定を閲覧する機能群

## スコープ
月次カレンダー表示、月切り替え、当日ハイライト、勤務種別の色分け

---

## ユーザーストーリー

### US-3.1: 月次カレンダー表示
**タイトル**: 勤務予定を月次カレンダーで表示する

As a 航空管制官,
I want 選択したセルの勤務予定を月ごとのカレンダー形式で確認したい,
So that 先の勤務予定を視覚的に把握できる.

**受け入れ基準**:
- [ ] 42日サイクル計算に基づいた勤務予定が月ごとに表示される
- [ ] 各日付に勤務種別（E1, A, B, C, E2, 明け, 休み, B4）が表示される
- [ ] 現在選択中のクルー名とセル名が画面上部に表示される

---

### US-3.2: 月の切り替え
**タイトル**: 表示月を切り替える

As a 航空管制官,
I want 先月や翌月へ表示を切り替えたい,
So that 異なる月の勤務予定を確認できる.

**受け入れ基準**:
- [ ] 翌月へ移動するボタンがある
- [ ] 先月へ移動するボタンがある
- [ ] 切り替え後、該当月の勤務予定が表示される

---

### US-3.3: 当日のハイライト表示
**タイトル**: 当日を強調表示する

As a 航空管制官,
I want 今日の日付が強調表示されていてほしい,
So that 今日の勤務予定をすぐに確認できる.

**受け入れ基準**:
- [ ] 当日の日付が他の日付と視覚的に区別できる
- [ ] 当月以外を表示中でも、当月に戻れば当日がハイライトされる

---

### US-3.4: 勤務種別の色分け表示
**タイトル**: 勤務種別を色分けで表示する

As a 航空管制官,
I want 勤務種別ごとに色分けされていてほしい,
So that 勤務パターンを一目で把握できる.

**受け入れ基準**:
- [ ] 各勤務種別（E1, A, B, C, E2, 明け, 休み, B4）が異なる色で表示される
- [ ] 土曜日・日曜日が識別できる色で表示される

---

### US-3.5: セル管理画面への戻り
**タイトル**: セル管理画面へ戻る

As a 航空管制官,
I want カレンダー画面からセル管理画面へ戻りたい,
So that 別のセルを選択できる.

**受け入れ基準**:
- [ ] 戻るボタンまたはナビゲーションが表示される
- [ ] 操作するとセル管理画面へ遷移する
