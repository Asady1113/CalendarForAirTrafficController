# エクスポートユニット

## 概要
勤務予定を外部へ出力する機能群

## スコープ
エクスポート期間設定、ICSファイルダウンロード、Googleカレンダー連携

---

## ユーザーストーリー

### US-4.1: エクスポート期間の設定
**タイトル**: エクスポート対象の期間を設定する

As a 航空管制官,
I want エクスポートしたい勤務予定の開始日と終了日を指定したい,
So that 必要な期間の勤務予定のみをエクスポートできる.

**受け入れ基準**:
- [ ] エクスポート開始日を選択できる
- [ ] エクスポート終了日を選択できる
- [ ] 選択した期間が表示される

---

### US-4.2: ICSファイルのダウンロード
**タイトル**: ICSファイルをダウンロードする

As a 航空管制官,
I want 勤務予定をICS形式でダウンロードしたい,
So that 任意のカレンダーアプリにインポートできる.

**受け入れ基準**:
- [ ] ICSダウンロードボタンが表示される
- [ ] ボタンを押すとICSファイルがダウンロードされる
- [ ] ダウンロードされたファイルに設定した期間の勤務予定が含まれる
- [ ] 各イベントに勤務種別と勤務時間が含まれる
- [ ] 各イベントのタイトルは「{アプリ名}_勤務種別」の形式で付けられる

---

### US-4.3: Googleカレンダーへのエクスポート
**タイトル**: Googleカレンダーに勤務予定をエクスポートする

As a 航空管制官,
I want 勤務予定をGoogleカレンダーに直接登録したい,
So that 普段使っているGoogleカレンダーで勤務予定を確認できる.

**受け入れ基準**:
- [ ] Googleカレンダー連携ボタンが表示される
- [ ] ボタンを押すとGoogleアカウントへの認証が求められる
- [ ] 認証後、設定した期間の勤務予定がGoogleカレンダーに登録される
- [ ] 各イベントに勤務種別と勤務時間が含まれる
- [ ] 各イベントのタイトルは「{アプリ名}_勤務種別」の形式で付けられる

---

### US-4.4: Googleカレンダーからの予定削除
**タイトル**: Googleカレンダーにエクスポートした予定を削除する

As a 航空管制官,
I want Googleカレンダーにエクスポートした勤務予定を削除したい,
So that 不要になった予定や誤ってエクスポートした予定を整理できる.

**受け入れ基準**:
- [ ] 削除したい範囲の開始日と終了日を指定できる
- [ ] 全期間の予定を一括削除するオプションがある
- [ ] 削除ボタンを押すとGoogleカレンダーから該当する予定が削除される
