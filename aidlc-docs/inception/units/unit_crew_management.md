# クルー管理ユニット

## 概要
勤務サイクルの基準となる「クルー」を管理する機能群

## スコープ
クルーのCRUD操作、クルー選択によるセル管理画面への遷移

---

## ユーザーストーリー

### US-1.1: クルー一覧の表示
**タイトル**: クルー一覧を表示する

As a 航空管制官,
I want 登録されている全てのクルーを一覧で確認したい,
So that 自分が所属するクルーを選択できる.

**受け入れ基準**:
- [ ] 登録済みの全クルーが一覧表示される
- [ ] 各クルーのクルー名とサイクル開始日が表示される
- [ ] クルーが未登録の場合、空の状態が適切に表示される

---

### US-1.2: クルーの新規作成
**タイトル**: 新しいクルーを登録する

As a 航空管制官,
I want 新しいクルーをクルー名とサイクル開始日を指定して登録したい,
So that 自分のクルー情報を管理できる.

**受け入れ基準**:
- [ ] クルー名を入力できる
- [ ] サイクル開始日（42日サイクルの起算日）を選択できる
- [ ] 登録ボタンを押すとクルーが保存される
- [ ] 登録後、クルー一覧に新しいクルーが表示される

---

### US-1.3: クルーの編集
**タイトル**: 既存のクルー情報を編集する

As a 航空管制官,
I want 登録済みのクルー名やサイクル開始日を変更したい,
So that クルー情報を最新の状態に保てる.

**受け入れ基準**:
- [ ] 編集したいクルーを選択できる
- [ ] クルー名を変更できる
- [ ] サイクル開始日を変更できる
- [ ] 保存ボタンを押すと変更が反映される

---

### US-1.4: クルーの削除
**タイトル**: 不要なクルーを削除する

As a 航空管制官,
I want 不要になったクルーを削除したい,
So that クルー一覧を整理できる.

**受け入れ基準**:
- [ ] 削除したいクルーを選択できる
- [ ] 削除前に確認ダイアログが表示される
- [ ] 削除を確定するとクルーが削除される
- [ ] クルーに紐づくセルも一緒に削除される

---

### US-1.5: クルーの選択（セル管理画面への遷移）
**タイトル**: クルーを選択してセル管理画面へ進む

As a 航空管制官,
I want クルーを選択してセル管理画面へ進みたい,
So that そのクルーに属するセルを管理できる.

**受け入れ基準**:
- [ ] クルー一覧から特定のクルーを選択できる
- [ ] 選択後、セル管理画面へ遷移する
- [ ] セル管理画面では選択したクルーの情報が表示される
