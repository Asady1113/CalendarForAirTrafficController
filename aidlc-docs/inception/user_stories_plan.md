# ユーザーストーリー作成計画

## 概要
航空管制官の勤務予定管理アプリケーションのユーザーストーリーを作成するための計画です。

---

## ステップ

### Phase 1: 準備・確認

- [x] **Step 1: ドメイン知識の確認**
  - ビジネスルール、ユビキタス言語の理解を確認する
  - 不明点があれば質問する

  [Question] 03_Ubiquitous.md の勤務種別「B4」の勤務時間が「？？？」となっています。B4の正確な勤務時間を教えてください。

  [Answer]
  Bと同じく、12:00~21:15です。
  不規則なBなのでB4と呼んでいるだけです。

- [x] **Step 2: ユーザーストーリーのフォーマット確認**
  - ユーザーストーリーの記述形式を決定する

  [Question] ユーザーストーリーのフォーマットは以下の形式でよろしいでしょうか？
  ```
  タイトル: [ストーリー名]
  As a [ユーザー種別],
  I want [機能・アクション],
  So that [得られる価値・理由].

  受け入れ基準:
  - [ ] 基準1
  - [ ] 基準2
  ```

  [Answer]
  いいです！

- [x] **Step 3: ユーザーペルソナの定義**
  - 主要なユーザータイプを特定する

  [Question] このアプリケーションを使用するユーザーは「航空管制官」のみでしょうか？管理者など他のユーザー種別は存在しますか？

  [Answer]
  航空管制官のみです。

### Phase 2: エピック（機能グループ）の定義

- [x] **Step 4: エピックの分類**
  - 要件ドキュメントに基づき、以下のエピックに分類する予定です：
    1. クルー管理
    2. セル管理
    3. 勤務予定カレンダー表示
    4. エクスポート機能（ICS・Googleカレンダー）

### Phase 3: ユーザーストーリーの作成

- [x] **Step 5: クルー管理のユーザーストーリー作成**
  - クルーの一覧表示
  - クルーの新規作成
  - クルーの編集
  - クルーの削除
  - クルーの選択（セル管理画面への遷移）

- [x] **Step 6: セル管理のユーザーストーリー作成**
  - セルの一覧表示
  - セルの新規作成
  - セルのサイクル構成編集
  - セルの削除
  - セルの選択（カレンダー画面への遷移）

- [x] **Step 7: 勤務予定カレンダー表示のユーザーストーリー作成**
  - 月次カレンダー表示
  - 月の切り替え（先月・翌月）
  - 当日のハイライト表示
  - 勤務種別の色分け表示

- [x] **Step 8: エクスポート機能のユーザーストーリー作成**
  - エクスポート期間の設定
  - ICSファイルのダウンロード
  - Googleカレンダーへのエクスポート

### Phase 4: 優先順位付けとレビュー

- [x] **Step 9: 優先順位付け**
  - 各ユーザーストーリーの優先度を決定する

  [Question] 優先順位付けの基準として、以下のどれを重視しますか？
  1. ビジネス価値（ユーザーにとっての重要度）
  2. 技術的依存関係（先に実装が必要なもの）
  3. リスク（技術的な不確実性が高いもの）
  4. 上記の組み合わせ

  [Answer]
  ビジネス価値です。

- [x] **Step 10: 最終レビューと調整**
  - 全ユーザーストーリーのレビュー
  - 必要に応じて修正・追加
