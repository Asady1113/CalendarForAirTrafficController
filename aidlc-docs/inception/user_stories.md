# ユーザーストーリー一覧

## プロジェクト概要
**アプリケーション名**: 航空管制官勤務予定管理アプリ
**目的**: 航空管制官が不規則な勤務体系の先の勤務予定を自動で算出し、カレンダーにエクスポートできるようにする

---

## ユーザーペルソナ

### 航空管制官
- 不規則な勤務体系（42日サイクル）で働いている
- 先の勤務予定を把握するために、自分でカレンダーを数える必要があり負担を感じている
- 勤務予定をGoogleカレンダーなどで管理したい

---

## エピック一覧

### Epic 1: クルー管理
**概要**: 勤務サイクルの基準となる「クルー」を管理する機能群
**スコープ**: クルーのCRUD操作、クルー選択によるセル管理画面への遷移

### Epic 2: セル管理
**概要**: クルーに紐づく「セル」とそのサイクル構成を管理する機能群
**スコープ**: セルのCRUD操作、サイクル構成（7ラウンドの順序・種別）の設定、セル選択によるカレンダー画面への遷移

### Epic 3: 勤務予定表示
**概要**: 計算された勤務予定を閲覧する機能群
**スコープ**: 月次カレンダー表示、月切り替え、当日ハイライト、勤務種別の色分け

### Epic 4: エクスポート機能
**概要**: 勤務予定を外部へ出力する機能群
**スコープ**: エクスポート期間設定、ICSファイルダウンロード、Googleカレンダー連携

### Epic 1: クルー管理

#### US-1.1: クルー一覧の表示
**タイトル**: クルー一覧を表示する

As a 航空管制官,
I want 登録されている全てのクルーを一覧で確認したい,
So that 自分が所属するクルーを選択できる.

**受け入れ基準**:
- [ ] 登録済みの全クルーが一覧表示される
- [ ] 各クルーのクルー名とサイクル開始日が表示される
- [ ] クルーが未登録の場合、空の状態が適切に表示される

---

#### US-1.2: クルーの新規作成
**タイトル**: 新しいクルーを登録する

As a 航空管制官,
I want 新しいクルーをクルー名とサイクル開始日を指定して登録したい,
So that 自分のクルー情報を管理できる.

**受け入れ基準**:
- [ ] クルー名を入力できる
- [ ] サイクル開始日（42日サイクルの起算日）を選択できる
- [ ] 登録ボタンを押すとクルーが保存される
- [ ] 登録後、クルー一覧に新しいクルーが表示される

---

#### US-1.3: クルーの編集
**タイトル**: 既存のクルー情報を編集する

As a 航空管制官,
I want 登録済みのクルー名やサイクル開始日を変更したい,
So that クルー情報を最新の状態に保てる.

**受け入れ基準**:
- [ ] 編集したいクルーを選択できる
- [ ] クルー名を変更できる
- [ ] サイクル開始日を変更できる
- [ ] 保存ボタンを押すと変更が反映される

---

#### US-1.4: クルーの削除
**タイトル**: 不要なクルーを削除する

As a 航空管制官,
I want 不要になったクルーを削除したい,
So that クルー一覧を整理できる.

**受け入れ基準**:
- [ ] 削除したいクルーを選択できる
- [ ] 削除前に確認ダイアログが表示される
- [ ] 削除を確定するとクルーが削除される
- [ ] クルーに紐づくセルも一緒に削除される

---

#### US-1.5: クルーの選択（セル管理画面への遷移）
**タイトル**: クルーを選択してセル管理画面へ進む

As a 航空管制官,
I want クルーを選択してセル管理画面へ進みたい,
So that そのクルーに属するセルを管理できる.

**受け入れ基準**:
- [ ] クルー一覧から特定のクルーを選択できる
- [ ] 選択後、セル管理画面へ遷移する
- [ ] セル管理画面では選択したクルーの情報が表示される

### Epic 3: 勤務予定表示

#### US-3.1: 月次カレンダー表示
**タイトル**: 勤務予定を月次カレンダーで表示する

As a 航空管制官,
I want 選択したセルの勤務予定を月ごとのカレンダー形式で確認したい,
So that 先の勤務予定を視覚的に把握できる.

**受け入れ基準**:
- [ ] 42日サイクル計算に基づいた勤務予定が月ごとに表示される
- [ ] 各日付に勤務種別（E1, A, B, C, E2, 明け, 休み, B4）が表示される
- [ ] 現在選択中のクルー名とセル名が画面上部に表示される

---

#### US-3.2: 月の切り替え
**タイトル**: 表示月を切り替える

As a 航空管制官,
I want 先月や翌月へ表示を切り替えたい,
So that 異なる月の勤務予定を確認できる.

**受け入れ基準**:
- [ ] 翌月へ移動するボタンがある
- [ ] 先月へ移動するボタンがある
- [ ] 切り替え後、該当月の勤務予定が表示される

### Epic 4: エクスポート機能

#### US-4.1: エクスポート期間の設定
**タイトル**: エクスポート対象の期間を設定する

As a 航空管制官,
I want エクスポートしたい勤務予定の開始日と終了日を指定したい,
So that 必要な期間の勤務予定のみをエクスポートできる.

**受け入れ基準**:
- [ ] エクスポート開始日を選択できる
- [ ] エクスポート終了日を選択できる
- [ ] 選択した期間が表示される

---

#### US-4.2: ICSファイルのダウンロード
**タイトル**: ICSファイルをダウンロードする

As a 航空管制官,
I want 勤務予定をICS形式でダウンロードしたい,
So that 任意のカレンダーアプリにインポートできる.

**受け入れ基準**:
- [ ] ICSダウンロードボタンが表示される
- [ ] ボタンを押すとICSファイルがダウンロードされる
- [ ] ダウンロードされたファイルに設定した期間の勤務予定が含まれる
- [ ] 各イベントに勤務種別と勤務時間が含まれる
- [ ] 各イベントのタイトルは「{アプリ名}_勤務種別」の形式で付けられる

---

#### US-4.3: Googleカレンダーへのエクスポート
**タイトル**: Googleカレンダーに勤務予定をエクスポートする

As a 航空管制官,
I want 勤務予定をGoogleカレンダーに直接登録したい,
So that 普段使っているGoogleカレンダーで勤務予定を確認できる.

**受け入れ基準**:
- [ ] Googleカレンダー連携ボタンが表示される
- [ ] ボタンを押すとGoogleアカウントへの認証が求められる
- [ ] 認証後、設定した期間の勤務予定がGoogleカレンダーに登録される
- [ ] 各イベントに勤務種別と勤務時間が含まれる
- [ ] 各イベントのタイトルは「{アプリ名}_勤務種別」の形式で付けられる

---

#### US-4.4: Googleカレンダーからの予定削除
**タイトル**: Googleカレンダーにエクスポートした予定を削除する

As a 航空管制官,
I want Googleカレンダーにエクスポートした勤務予定を削除したい,
So that 不要になった予定や誤ってエクスポートした予定を整理できる.

**受け入れ基準**:
- [ ] 削除したい範囲の開始日と終了日を指定できる
- [ ] 全期間の予定を一括削除するオプションがある
- [ ] 削除ボタンを押すとGoogleカレンダーから該当する予定が削除される
