# 機能一覧

アプリケーションの画面遷移（クルー → セル → カレンダー）に基づき、各画面が提供する機能を整理しました。

## 1. クルー管理画面
勤務サイクルの基準となる「クルー」を管理・選択する画面です。

*   **クルーの管理（CRUD）**
    *   **一覧表示**: 登録されている全てのクルーを表示します。
    *   **新規作成**: クルー名とサイクル開始日（42日サイクルの起算日）を指定して登録します。
    *   **編集**: 既存のクルー名やサイクル開始日を変更します。
    *   **削除**: 不要になったクルーを削除します。
*   **画面遷移**
    *   **クルー選択**: 編集・閲覧したいクルーを選択し、セル管理画面へ進みます。

## 2. セル管理画面
クルーに紐づくセルごとの勤務パターンを構成・管理する画面です。

*   **セルの管理（CRUD）**
    *   **一覧表示**: 選択中のクルーに紐づく全てのセルを表示します。
    *   **新規作成**: 新しいセルを追加登録します。
    *   **構成の編集**: セルごとに7ラウンドの順序と、各ラウンドの種別（夜勤あり／夜勤なし／夜勤なし・B4あり）を設定します。
    *   **削除**: 不要になったセルを削除します。
*   **画面遷移**
    *   **セル選択**: 特定のセルを選択し、カレンダー画面へ進みます。
    *   **戻る**: クルー管理画面へ戻ります。

## 3. カレンダー・エクスポート画面
計算された勤務予定を閲覧し、外部へ出力する画面です。

*   **勤務予定の閲覧**
    *   **月次カレンダー表示**: 42日サイクル計算に基づいたシフトを月ごとに表示します。日付（土日）や勤務種別を色分けで識別できます。
    *   **表示切り替え**: 先月・翌月への移動や、当日のハイライト表示を行います。
*   **外部出力（エクスポート）**
    *   **期間設定**: エクスポート対象とする開始日と終了日を指定します。
    *   **ファイル保存**: ICS形式でスケジュールをダウンロードします。
    *   **クラウド同期**: Googleカレンダーへ予定を直接登録します。
*   **画面遷移**
    *   **戻る**: セル管理画面へ戻ります。
